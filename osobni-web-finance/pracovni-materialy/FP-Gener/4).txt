4) Checklist pro Gemini (verze “ať se nezalkne”)
Zásada

Gemini nesmí dělat vše naráz. Uděláme 5 malých úloh.

Úloha 1/5: Skeleton + state model

Zadání pro Gemini:

vytvoř blank app strukturu (index + app.js + modules + data json)

central state objekt:

client { name, dob, email, phone, professionRisk }

partner? { name, dob }

children[] { name, dob }

cashflow { netIncome, grossIncome, expenses }

assets { reserve, investmentsLumpSum, investmentsRegular, pension, other }

debts { mortgage, loans }

goals[] (typ, částka/renta, horizont, startCapital)

productsSelected[] (id, amount, horizon, expectedReturn)

insuranceNeeds { disability, pn, death, permanent, do }

validace + parse date z pasted textu

Úloha 2/5: Cashflow + majetek (oprava bugů)

správné sčítání / odečítání

formátování Kč

rezerva: vyhodnocení “splněno / plán tvorby”

UI: inputy + summary cards + graf (cashflow donut / bar)

Úloha 3/5: Cíle + výpočty investic

renta logika 6% (1 mil ~ 5k)

výpočet cílového kapitálu z cílové renty

výpočet potřebné měsíční investice se start kapitálem

strategie dynam/ vyváž/ konzerv = 9/7/5

graf růstu cíle

Úloha 4/5: Produkty + popisy

products.json se všemi fondy a parametry (výnosy výše)

vygenerovat “produktové karty” ve výstupu (delší text, odstavce, bullet points)

extra sekce “jednorázové vs pravidelné vs penze”

Úloha 5/5: Pojištění (PN, invalidita, smrt…)

PN: převod čistá→hrubá (aprox) + DVZ (zjednodušený model) + odhad nemocenské ~60% z DVZ

invalidita/smrt: odečíst rezervy a relevantní investice

smrt navázat na děti+partner+úvěr

trvalé následky + DO: pravidla a zdůvodnění

výstup: rozpis “proč tolik” + tabulka + graf
